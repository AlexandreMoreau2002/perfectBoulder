**Perdu ? Commence ici.**

---

## Comment ce projet fonctionne

```
1. DECIDER   →  docs/WORKFLOW.md      (decisions + etape en cours)
2. SPECIFIER →  docs/prd.md           (quoi construire)
3. CONCEVOIR →  docs/specs/           (comment ca marche, page par page)
4. CODER     →  mobile/ + backend/    (implementation)
5. REFERENCE →  docs/lexique.md       (vocabulaire commun)
```

---

## Ou aller selon ce que tu veux faire

| Je veux... | Va lire |
|------------|---------|
| Savoir ou on en est | `docs/WORKFLOW.md` |
| Savoir ce qu'on construit | `docs/prd.md` |
| Comprendre un terme (croix, session, post...) | `docs/lexique.md` |
| Lire la spec d'une page | `docs/specs/` (quand ca existera) |
| Comprendre l'archi backend | `CLAUDE.md` section Backend |
| Comprendre l'archi mobile | `CLAUDE.md` section Mobile |
| Les regles de code | `CLAUDE.md` + `.agent/` |

---

## Regles

1. **WORKFLOW.md est le chef** - C'est lui qui dit quoi faire ensuite
2. **prd.md est la verite** - En cas de doute sur le scope, c'est lui qui decide
3. **1 doc par sujet** - Pas 3 fichiers qui disent des choses differentes
4. **Court > Long** - Si un doc fait plus de 2 pages, il est trop long
5. **Pas de doc "a creer"** - On cree quand on en a besoin, pas avant
