# P05 - Ajouter Contenu

## Objectif
Offrir un point d'entrée unique pour créer n'importe quel contenu pertinent.

## MVP Minimal
1. Choix du type de contenu:
   - Nouvelle session
   - Nouvelle croix
   - Post vidéo/photo
2. Parcours guidé selon type choisi
3. Validation et publication/enregistrement
4. Feedback succès + redirection logique

## Évolutions
- Brouillons
- Préremplissage intelligent (salle/date)
- Multi-upload
- Publication planifiée
