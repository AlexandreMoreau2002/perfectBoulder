# P04 - Home Video Feed

## Objectif
Afficher un feed vidéo engageant de contenu publié par les autres utilisateurs.

## MVP Minimal
1. Feed vertical vidéo
2. Carte vidéo: auteur, salle, niveau/couleur, caption
3. Actions rapides: like, commentaire, partage/sauvegarde (simple)
4. Filtres: `Suivis` / `Local`
5. Pull-to-refresh
6. Empty state

## Évolutions
- Feed algorithmique `Pour toi`
- Stories
- Recommandations de blocs/salles
- Défis du jour
